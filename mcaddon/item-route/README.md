# 🧺 item-route · 物品路由仓库

**MCBE 智能仓库管理 Add-On** — 自动分拣、容器整理、仓库统计、容量预警、物品搜索、信物交互

</div>

---

## 📖 这是什么

一个 **Minecraft Bedrock 原版官方模组（Script API）**，把"仓库"变成能自己会收纳的智能空间：

- 你在仓库任意口/漏斗丢入物品，它会把物品**自动分拣**到对应容器（单物箱、多物箱、同族箱、杂项桶）。
- 提供 **容器整理**（就地排位 + 合并堆叠）、**统计报表**、**容量预警**、**物品搜索**。
- 一切通过**信物（木锄）**交互与 `/ir:*` 命令操作，中文菜单，无需逐格放置漏斗与指令。

`item-route` 同时是这个 monorepo 的 **参考架构**（六边形/分层：`core` 纯逻辑 + `mc` 适配层），开发者架构说明见同目录 `AGENTS.md`。

## 核心概念

| 概念 | 含义 |
|---|---|
| **仓库** | 一个矩形区域（维度 + 两对角点），区域内方块自动被识别为容器。owner 创建、member 管理 |
| **信物** | 默认 `木锄`（wooden_hoe）。手持信物右键与世界交互：点容器进配置、点空处选区建仓 |
| **容器角色** | 每个容器有角色：`input`（漏斗/输入）、`single`（单物）、`multi`（多物）、`misc`（杂项/兜底） |
| **物品族** | 一组"同类"物品（羊毛/地毯/玻璃/原木/农作物…）。仓库可开"同族收纳"，多物箱装某族任一成员 → 收全族 |
| **路由** | 输入容器里的物品 → 按规则自动分送到合适容器 |
| **索引** | 内存中的物品→容器 O(1) 索引，路由/搜索共用（纯运行时，激活时重建） |
| **成员** | 仓库参与者：`owner`（全部权限）/ `member`（管理成员）。非成员不可操作 |

## 快速开始

1. 把生成的 `.mcpack`/`.mcaddon` 导入你的世界（行为包 + 资源包）。
2. 进入游戏，拿一把 **木锄**。
3. 手持木锄，先后右键两个对角方块（第一次记录角点 1，第二次确定角点 2）→ 仓库区域创建完成，边界发光提示。
4. 在仓库区域内放置箱子，然后到仓库菜单「刷新容器」（或 `/ir:rescan 仓库名`）让模组识别这些容器。
5. 给箱子分配角色：
   - 单物箱（`single`）：一个箱子只放一种物品
   - 多物箱（`multi`）：一个箱子可收多种物品；开启同族收纳后可按族自动归类
   - 输入箱（`input`，漏斗）：物品暂住地，供路由自动分拣
   - 杂项（`misc`）：找不到归属时收纳
6. 往输入箱里丢东西 → 自动分拣开始；也可用 `/ir:menu` 搜索、整理、查看统计。

> 不需要指令也能建仓——全程信物即可。命令是纯快捷入口。

## 使用指南

### 信物（默认：木锄）

| 操作 | 效果 |
|---|---|
| 右键 **容器** | 打开该容器配置菜单（改角色 / 启用 / 预警 / 优先级 / 整理 / 同族 / 黑白名单） |
| **潜行** + 右键 容器 | 单容器就地整理 |
| 右键 **非容器方块** | 选区模式（第一次点击记录角点 1 → 第二次点击确定对角点）→ 创建仓库 |
| **潜行** + 右键 非容器 | 打开仓库管理菜单 |
| **长按**右键（isFirstEvent=false） | 打开仓库菜单 |

### 主菜单 `/ir:menu`

| 项 | 作用 |
|---|---|
| 容器搜索 | 选仓库 → 输关键词 → 命中物品 + 紫粒子标记位置 |
| 管理仓库 | 就近找你有权限的仓库，直达其设置 |
| 仓库列表 | 全部可管理仓库列表 |
| 创建仓库 | 两步选区方式建仓 |
| 帮助 | 图文介绍 |
| 模组配置（仅管理员 OP） | 全局开关/速度上限/信物/建仓限制/全服统计/菜单信息开关 |

### 仓库设置页（查看 / 修改）

- **基本信息**：仓库 ID / 维度 / 范围坐标 / 规格 / 启用族数（可模块化开关，见管理员配置）
- **默认新容器**：角色、是否默认启用
- **处理速度**：路由 tick 间隔（快 → 频繁路由）
- **仓库运转**：总开关
- **自动整理**：路由成功且混乱度高时自动整理
- **边界光幕**：持续显示仓库边界（持信物可见）
- **容量预警**：仓库级预警开关
- **操作项**（一次一个）：刷新容器 / 修复仓库 / 容器角色 / 同族配置 / 仓库黑名单 / 成员管理 / 统计 / 调整区域 / 删除仓库

### 容器配置页

- 类型/容量/混乱度容器 ID / 状态 / 角色 / 优先级（+ 族榜，若启用同族）
- 启用开关 / 角色下拉（漏斗强制 input）
- 路由优先级（1-100 小者先）
- 立即整理（就地）
- 该容器容量预警
- **同族收纳**（仅 multi）：装某族任一成员 → 收全族
- **白名单 / 黑名单** 编辑（物品多选器）

## 路由机制详解

### 分拣顺序（五级）

```
输入容器（漏斗/丢入）
   ↓
① 单物箱（绑定该物品类型的 single）
② 多物箱（已装同品种）multi
③ 同族箱（装了集合内某族的成员）family → 认族后族内新色也可收
④ 杂项箱（misc 兜底）
   ↓
找不到：物品留在源（不丢），后期会再试
```

- 每条链路都先经**容器级黑名单**（命中 → 永不进该容器）；白名单 = 声明式允许（缺物也能进）。
- **仓库级黑名单**：命中物品 → 输入必阻塞（永不进入该仓库），并触发预警。
- 索引是 O(1) 全容器索引（single/multi/misc 桶），激活即全量重建，路由移动即时更新。

### 同族收纳（family）详解

1. 仓库设置 → **同族配置**：勾选你要开的族（默认启用核心族）。
2. 某个**多物容器** → 容器配置 → 开启**同族收纳**。
3. 此时若该箱装了白羊毛（wool 族成员）→ 它会自动收一族全部羊毛（橙/红/黑…）。
4. 族桶由容器内容自动派生（白/橙任一都在羊毛族 → 自动归族）。
5. 族榜会显示容器内各族排行。

### 自动整理

- 打开"自动整理"并设阈值（0-100，推荐 40）：路由每一次成功传动目标箱后，若该箱混乱度超阈值 → 自动就地整理。
- 手动：容器配置里"立即整理"，或潜行点容器 / 背包整理（主栏 → 快捷栏副栏）。

### 搜索（O(1) 命中）

- 入口：命令 `/ir:search 关键词` 或 菜单 → 容器搜索。
- 支持：typeId（`netherite_sword`）、中文（`下界合金剑`）、英文名（`Netherite Sword`）模糊匹配。
- 命中类型**不截断**（全宇宙），每行容器最多显示 1 个，多余折叠为 `+N`；命中箱位置释放紫粒子。
- 索引 + 实时兜底：索引是运行时缓存，玩家手动改箱可能未同步 → 搜索以索引为主、实时扫描兜底并集，**不漏报**。

## 数据结构与存储

- 所有数据存在于 **Dynamic Properties**（世界存档内），无外部数据库，开箱即读。
- **仓库 meta**：单键（`ir2:wh:{id}:meta`）；**容器注册表**：每容器一条（`ir2:c:{cid}`）；
- **统计**：每容器一条（`ir2:cst:{cid}`）；**cids 索引**：每仓一条（`ir2:wh:{id}:cids`）。
- **索引（byItem/族桶）不落盘**——纯运行时缓存，激活时按真实内容全量重建，卸载即清（永远最新、零写入放大）。
- 事件驱动写穿，**无定时 flush**；容器级数据只写改动的那一个容器（最小单位）。

### 数据安全约定

- **不吞物**：路由/整理不会凭空吞掉物品（原子移动 + 源引用保留）。
- **不覆盖/不刷物**：堆叠判定委托原生 `mc.addItem`（NBT 级），绝不错误合并或复制。
- 所有方块/容器访问 try-catch：区块卸载时不崩。

## 常见问题

**Q：为什么物品没自动分拣？**
1. 仓库是否已激活（玩家靠近区域内、输入容器有物品）？
2. 仓库是否开启"仓库运转"开关？
3. 该物品是否有"去路"（单物/多物/同族/杂项至少一个可用容器）？
4. 是否被仓库级/容器级黑名单拦住（这时会提示输入阻塞预警）？

**Q：`misc` 箱子收不到？**
检查杂项箱是否为 `enabled` 且角色为 `misc`；若杂项被全部禁用/黑名单拦死 → 物品留在输入。

**Q：为什么某些物品搜不到？**
搜索支持中文/ID/英文，若索引不稳定但系统实时扫描兜底覆盖——应能命中。必要时运行"修复仓库"重建索引。

**Q：想换信物 / 改速度 / 限仓？**
OP 打开 模组配置 修改即可。

## 开发者文档

- **架构、命令、测试、构建** 详见同目录 [`AGENTS.md`](./AGENTS.md)。

```
scripts/

│   ├── stats/        # 统计 + 预警

│   └── storage/   # 仓储接口 + 内存替身
└── mc/             # 适配层（持久化/视觉/交互/菜单/命令）
```
