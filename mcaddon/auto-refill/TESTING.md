# AutoRefill 功能测试清单

> 目的：按流程逐项验证 v2.0.0 的「工具/武器选择引擎（**两级偏好：附魔 1 级优先 + 工具 2 级优先**）+ 耐久保护（占比阈值+绝对下限）+ 消耗品补充 + 管理员菜单」全部功能。
> 每项记录：**准备 / 操作 / 预期 / 结果**。预期列标注了会出现在**内容日志（Content Log）**里的 `[AutoRefill]` 行与级别（debug/info/warn/error）。

## 1. 加载与菜单

| # | 操作 | 预期 | ✅ |
|---|---|---|---|
| 1.1 | 输入 `/ar:menu` | 弹出 **ModalForm**（5 个开关 toggle + 滑条"耐久保护阈值" + 滑条"耐久绝对下限"），开关显示当前状态 | ☐ |
| 1.2 | 改动任一开关并点"保存" | 收到 `§a已保存「自动替换」配置`；重开菜单状态已更新 | ☐ |

| 1.5 | 非操作员玩家执行 `/ar:menu` | 提示无权限，菜单不弹出 | ☐ |

> 命令在**安全上下文**执行：若旧版会报"Script Error: 不在安全上下文"，现不报错即为通过。

| # | 操作 | 预期 | ✅ |

## 5 分钟冒烟（回归版：全开默认跑一遍）

1. 空手挖石头 → 镐 · 挖草方块 → 精准锹完美草方块 · 挖玻璃 → 精准镐 · 挖树叶 → 精准锄 · 挖小麦 → 时运锄
2. 空手打僵尸 → 亡灵杀手剑（打猪 → 锋利剑（无锋利则剑））
3. 石镐磨破 → 破碎补齐
4. 吃苹果到空 → 自动补
5. `/ar:menu` 拨全局关 → 全部停 → 拨回开
6. 内容日志全程无 `error`
