# 模拟玩家（MockPlayer）更新日志

> 面向玩家/服主的更新说明（1.1.40 → 2.3.3）。
> 部署方式：将对应版本 `.mcaddon` 放入行为包目录，重启世界生效。

### 2.3.4（全部工作模式独立调度 + 行为能力完善）
- **自动跟随收编任务运行时**（原 10 tick 共享轮询引擎删除）：
  - 事件驱动独立调度：每假人独立协程，0.5 秒决策 + 持续注视目标
  - 跟随目标持久化：服务器重启后自动恢复跟随（玩家重连也能按名找回）
  - 目标离线/超距 128 格自然停止；投掷三叉戟期间自动暂停跟随
- **自动挖掘完善**：按目标方块类型自动换最优工具（镐/斧/锹/锄/剑全映射 +
  品阶/附魔评分，全背包扫描选最优）；目标被外部改动自动重选（绝不挖错方块）
- **自动放置完善**：主手方块自动补位——主手空/非方块时从背包自动换上可放置方块
- **自动攻击完善**：视线锁定目标定向连击（不再每击抖动重选）+ 自动选最优武器
  （剑 > 斧，锋利附魔优先）
- 新增挖掘/武器策略单测 16 例（rules/items/MineToolRules，纯函数可单测）

## 2.3.x —— 任务运行时架构 + 假人行为 BUG 修复

### 2.3.3（架构收口 + 文档铁律）
- **定点破坏铁律**入档（机制约束，防未来回退）：
  - 破坏执行只挖**目标坐标上类型已验证**的方块，全程类型守卫（类型变化即停手）
  - 根治砍树"挖泥巴/挖坑"：不再用视线射线替代目标坐标
- **模块开发文档收口**：任务运行时 / 异常体系 / 工作模式 / 资源池规范

### 2.3.2（事件驱动任务运行时 + 阶段机，架构重构）
- **移除三套旧 AI 引擎**（旧行为树 / 生物 AI 框架 / 10 tick 引擎，-4500 行）：
  - 根治高频计算导致的游戏挂起/崩溃风险；零常驻轮询，全部事件驱动
- **六任务统一阶段机**（挖掘/放置/攻击/闲逛/钓鱼/砍树）：
  - **恢复自动砍树模式**（砍树子模式：原木 / 收集树叶）
  - **修复自动挖掘空挡**：far/busy/blocked 一律回探测重新选目标（杜绝原地隔山打牛死循环），方块一碎立即衔接下一块
  - **修复大树浮空木无限寻路**：竖向够不到直接放弃该目标（上封顶剪枝），不再反复无效寻路
  - **修复连体树双假人抢砍**：相邻树整树占地互斥认领
- **资源池统一**：钓鱼点池 / 树池共享、认领、扫描隔离机制只实现一遍

### 2.3.1（异常体系 + 基础动作层修复）
- **自定义异常体系**：动作失败统一携带 reason 码 + 根因（日志可诊断性提升）
- **修复挖掘打不中**：破坏前身体+视线同时面向目标方块中心
- **修复拾取僵硬/不看掉落物**：走过去的同时身体与视线面向掉落物
- **修复自动跟随不看向目标**：跟随全程持续注视主人（移动中/停住后）
- **修复钓鱼对准**：发杆前统一面向钓鱼点

## 1.1.6x —— 劫掠机制完善

- 袭击阶段估算日志（预触发 → 开始 → 波次 → 冷却 → 胜利/停战）

### 1.1.60 ~ 1.1.65（机制修正批次）
- **喝瓶周期修复**：劫掠假人**只在启动和胜利后喝药水**（兆头消失也不会反复喝，不浪费药水）

## 1.1.5x —— 行为树 AI 时代

## 使用提示

- **劫掠模式**：把假人放到村庄/试炼之地内开启，假人会自主喝药水 → 刷袭击 → 胜利后自动续瓶；主人会收到每个阶段的通知
- **宝库模式**：把钥匙放入假人背包即可（主手自动切换），假人自动寻路开箱并循环重连
- **管理员**：`/mp:admin` 打开管理员菜单（全览 + 配额 + 名单）；`/mp:test` 传送到测试维度
