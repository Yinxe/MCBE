# 模拟玩家（MockPlayer）更新日志

> 面向玩家/服主的更新说明（1.1.40 → 2.3.3）。
> 部署方式：将对应版本 `.mcaddon` 放入行为包目录，重启世界生效。

### 2.4.1（资源分配与占用设计修正：认领租约 + 墓碑 + 排除集）
- **修复长作业丢认领导致双假人抢同一资源**：认领有效性不再看"整池 60 秒内
  有没有写过"（砍大树/长导航+45 秒咬钩期间不写池，池一过期认领就蒸发，
  另一假人重扫认领同一棵树/同一钓点）——改为看"持有者任务还在不在跑"
  （读时惰性判定）+ 认领租约兜底；释放带占用者校验（防误释他人认领）；
  预重扫回写只替换自己仍持有的条目（防覆盖他人认领）
- **放弃的树立墓碑不再"复活"**：留顶剪枝的高树顶还在世界里，之前 remove 后
  下次扫描当"新树"认领 → 白跑 → 剪枝 → 移除 → 永动机空转；现在 exhaust 立
  墓碑保留条目（重扫不再发现为新，`noTreeFound` 终态可达），复活期 10 分钟
  后惰性复活；钓鱼三振点同理复活（不再"永不复活"，池只进不出）
- **修复 align 失败死循环**：导航/对齐失败释放后，该点仍是星级最高 → 下轮
  又选回同一个 → 无限打转；失败点进本轮排除集（钓到鱼清空）
- **认领前现场校验**：树基座仍是原木才认领（池数据陈旧的最后一道门）；
  已不在的树真移除 + 排除再试（自清洁）
- 池键永不过期（条目级时间戳替代整池 TTL）；free 数据过期触发重扫刷新

### 2.4.0（工具策略引擎化——@yinxe/tool-strategy 接入）
- **挖掘/砍树/攻击的工具选择统一接入可插拔引擎**（替代三处自写加权评分）：
  - **耐久保护**（全新能力）：剩余耐久 < 5% 或 < 16 点的工具不再当选；
    主手快断时强制换装——此前实现快断的镐照样当选，假人会挖到工具报废
  - **档位手排**：跨档交叉优先级成为可能（如"效率5铁斧 > 精准钻石镐 > 效率3
    铁斧"），加权评分表达不了的场景引擎原生支持
  - **附魔硬门槛**：树叶收集的"必须精准/剪刀"从软加分升级为硬性档位
  - 三处消费方全部切换：定点挖掘（MINE_TREE 方块角色分发）、砍树（原木效率
    斧/树叶四档手排）、攻击（剑>斧+锋利链）；旧评分实现与测试成对退役
  - 假人背包快照升级：含角色/品阶/**耐久**/附魔；非工具物品不再入池
    （砍树不换斧头 BUG 的"杂物兜底"根因从数据层根除）

### 2.3.7（砍树工具择优修复 + 磁吸拾取重构）
- **修复砍树不换斧头（BUG2）**：
  - 两处根因：① 评分甄别漏洞——背包杂物（泥土/圆木等）被兜底归"斧类"0 分
    参与评选；② 换装倒腾死锁——斧头换到主手后再次选优指向主手槽自身，切换
    失败被静默吞掉，导致背包明明有斧头却永远换不上
  - 修复：只认真工具（斧头/锄头/剪刀/精准附魔）参与评分；主手已是最优工具
    不再折腾换装；定点挖掘（非智能挂机）与砍树（智能模式）的工具择优均生效
- **拾取机制重构——磁吸传送拾取**（替代旧"走过去捡"）：
  - 砍树每棵树完成后、钓鱼每轮收竿后，扫描假人**半径 10 格**内感兴趣的掉落物，
    直接**传送到假人脚下**，约 0.5 秒自动完成拾取
  - 零寻路零走动：不再导航走向掉落物（旧思路慢、可能卡在地形上、多目标来回跑）
  - 掉落物白名单按**物品 ID** 匹配（修复方块 ID 与掉落物 ID 混用：树叶破坏
    掉的是树苗/苹果/木棍而非树叶本体）；钓鱼只吸鱼获类（不误吸他人掉落）
- 新增磁吸白名单单测 7 例（树苗/鱼获防回退）

### 2.3.6（定点挖掘改无意识挂机语义）
- **定点挖掘 = 无意识挂机**（与智能挖掘的本质区别）：
  - 用户预先调整假人姿态与视角（控体态、转头）后开启——**视角是任务输入**
  - 挖掘期间**绝不改动姿态/视角**（不再自动面向方块、不再扭头）
  - 沿当前视线方向持续挖掘：挖穿后视线自然伸到下一块，连续挖掘无空挡
  - 视线被方块遮挡则沿新视线继续（不隔山打牛）
  - **保留自动工具选择**：按视线方块类型自动换最优工具（镐/斧/锹/锄/剑）
  - 保留类型守卫：目标被外部改动即重新探测（绝不挖错方块）

### 2.3.5（深度审查修复：状态漂移/竞态/性能）
- **修复任务自然完成后的状态漂移**：任务自然完成（如砍完附近无树、跟随目标离线）
  → 工作模式自动归零「空闲」（此前记录/UI 仍显示原模式，且事件对账会空转重启
  秒退任务）；取消退出（切换模式/下线/死亡）不归零
- **修复跟随启动竞态**：`/mp:follow` 与行为菜单先把跟随目标写入记录、再切换
  工作模式（目标就位后才启动任务，杜绝"启动即秒退归零"）；任务对目标字段
  迟到另有 0.5 秒短等容错
- **修复停止跟随误伤其他模式**：残留跟随目标清理只清目标字段，仅当前确为跟随
  模式才切回空闲（防把玩家已手动切换的挖掘等模式误归零）
- **攻击任务性能优化**：武器策略移到锁定目标时一次换装（连击期间不再每 4 tick
  全背包 36 格快照 + 附魔读取）；`attackEntity` 引擎可无视距离打击——strike
  距离自检（目标被击退跑远即回探测重新锁定，防无限追打远距目标）
- 运行时类型收口：followTask 目标解析改用完整 BotRecord 类型（去 as 断言）

## 使用提示

- **劫掠模式**：把假人放到村庄/试炼之地内开启，假人会自主喝药水 → 刷袭击 → 胜利后自动续瓶；主人会收到每个阶段的通知
- **宝库模式**：把钥匙放入假人背包即可（主手自动切换），假人自动寻路开箱并循环重连
- **管理员**：`/mp:admin` 打开管理员菜单（全览 + 配额 + 名单）；`/mp:test` 传送到测试维度
