# Spec Delta

## MODIFIED Requirements

### Requirement: 传送转场总开关与风格

模组 MUST 提供世界级配置项 `transitionEnabled`(总开关)与 `transitionStyle`(风格)。总开关默认 MUST 为开启,风格默认 MUST 为电影感。风格 MUST 限于「电影感」「淡入淡出」「关闭」三档,无法识别的取值 MUST 回落到默认风格。两项配置 MUST 在重启后保持。

总开关关闭时,MUST 对**全部**传送入口一致生效,MUST NOT 被任何入口特例覆盖:关闭语义是「不要任何动画」,包括死亡点回传的快速淡入在内,一律直接位移。总开关开启时,各入口按风格执行,死亡点回传另按「死亡点回传使用快速淡入」要求降档。

#### Scenario: 默认开启

- **WHEN** 一个从未配置过转场的世界安装本模组并执行一次传送
- **THEN** 传送带有完整的电影感运镜

#### Scenario: 总开关关闭

- **WHEN** 管理员把总开关关闭
- **THEN** 所有传送入口都直接位移,不播放任何相机动画

#### Scenario: 关闭时死亡点回传也无动画

- **WHEN** 管理员把总开关关闭后玩家执行 `/tpa:back`
- **THEN** 玩家直接出现在最近死亡点,不播放快速淡入,也不播放运镜

#### Scenario: 选择淡入淡出风格

- **WHEN** 管理员把风格设为淡入淡出
- **THEN** 传送以黑屏淡入淡出完成,不播放运镜

#### Scenario: 配置损坏回落默认

- **WHEN** 世界存档中的风格取值不是三档之一
- **THEN** 模组按电影感风格执行,不报错

### Requirement: 跨维度传送降档为淡入淡出

玩家所在维度与落点维度不同时,模组 MUST NOT 播放运镜,而 MUST 以黑屏淡入淡出完成传送。淡入淡出 MUST 在玩家看不见的时段内完成位移。运镜 MUST NOT 跨越维度边界,因为相机无法随玩家跨维度存续。

死亡点回传跨维度时,MUST 使用「死亡点回传使用快速淡入」要求的快速淡入,而不是本节所述的常规淡入淡出。

#### Scenario: 跨维度不播运镜

- **WHEN** 玩家从主世界传送到下界的传送点
- **THEN** 传送以黑屏淡入淡出完成,不出现相机飞越维度的画面

#### Scenario: 位移在遮黑期间完成

- **WHEN** 观察一次跨维度传送
- **THEN** 玩家看不到自己瞬移的瞬间,画面恢复时已在落点

#### Scenario: 同维度仍用运镜

- **WHEN** 转场风格为电影感,玩家在同维度内传送到自己的传送点
- **THEN** 传送使用运镜而不是淡入淡出

#### Scenario: 死亡点跨维度回传用快速淡入

- **WHEN** 玩家在下界死亡、重生后执行 `/tpa:back` 回到主世界的死亡点
- **THEN** 传送使用快速淡入,而不是常规的淡入淡出或运镜

## ADDED Requirements

### Requirement: 死亡点回传使用快速淡入

死亡点回传 MUST 使用专用的快速淡入,而不是电影感运镜。快速淡入的完整时长 MUST 短于常规淡入淡出,以便把玩家的不可操作窗口压到最短。

快速淡入 MUST 覆盖死亡点回传的全部入口:回传命令、死亡点列表、死亡重生后的回传对话框。MUST NOT 只在其中一部分入口生效。

快速淡入 MUST 在画面被完全遮黑期间提交位移,使玩家看不到瞬移的瞬间。

#### Scenario: 回传命令不播运镜

- **WHEN** 转场风格为电影感,玩家执行 `/tpa:back` 且最近死亡点与玩家同维度
- **THEN** 传送使用快速淡入,不出现相机脱离玩家或飞越高空的画面

#### Scenario: 死亡点列表不播运镜

- **WHEN** 玩家打开死亡点列表并选择其中一条
- **THEN** 传送使用快速淡入,不播放运镜

#### Scenario: 重生对话框不播运镜

- **WHEN** 玩家死亡重生后,在回传对话框中选择「传送」
- **THEN** 传送使用快速淡入,不播放运镜

#### Scenario: 快速淡入比常规淡入淡出更短

- **WHEN** 对比一次死亡点回传与一次跨维度传送的遮黑时长
- **THEN** 死亡点回传的完整淡入淡出时长明显更短

#### Scenario: 位移在遮黑期间完成

- **WHEN** 观察一次死亡点回传
- **THEN** 玩家看不到自己瞬移的瞬间,画面恢复时已在死亡点

#### Scenario: 回传后立即恢复操作

- **WHEN** 一次死亡点回传结束
- **THEN** 玩家可以立即移动与转视角,输入权限已恢复

### Requirement: 传送意图决定执行方式

模组 MUST 区分「普通传送」与「死亡点回传」两种传送意图,并据此选择执行方式。判定 MUST 由调用方显式声明意图,而不是依据目标坐标、维度或目标名称推断。

执行方式的判定顺序 MUST 为:总开关关闭则直接位移;死亡点回传则快速淡入;跨维度则常规淡入淡出;其余按全局风格执行。

#### Scenario: 同一目标两种意图

- **WHEN** 玩家先通过死亡点列表回传,再把自己的一个传送点设在同一坐标并传送到该传送点
- **THEN** 前者使用快速淡入,后者按全局风格播放运镜

#### Scenario: 关闭优先于意图

- **WHEN** 总开关关闭,玩家执行死亡点回传
- **THEN** 直接位移,不播放快速淡入

#### Scenario: 死亡点跨维度也降档

- **WHEN** 死亡点与玩家不在同一维度,玩家执行回传
- **THEN** 使用快速淡入,而不是常规淡入淡出
